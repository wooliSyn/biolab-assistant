# 传送门图标来源

本目录图标分两批：

1. **33 个**由 `fetch-portal-icons.mjs` 从各站点自身的 favicon / apple-touch-icon 抓取（见脚本注释）。
2. **9 个**期刊与工具的刊名字标为单独补充，出处如下。

检索日期：2026-11-15。PNG 可直接使用，SVG 可无损缩放；PNG 由矢量文件渲染时未改变标志颜色和比例。Cell 和 DAVID 保留来源图片的原始分辨率。
