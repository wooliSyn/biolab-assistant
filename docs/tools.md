## 计时

### 秒表

开始 / 暂停 / 计次 / 重置。计次记录按下时的累计时间，不是两次之间的间隔。

- 工具箱常驻挂载，**切到别的页面秒表继续走**，回来时数值不变。
- 计时以 1 秒为步长（`setInterval(1000)`），不适合需要亚秒精度的场合。

### 倒计时

预设 1 / 3 / 5 / 10 / 15 / 30 分钟，或自定义「分 + 秒」。

- 到点：显示 `00:00` 并闪烁，同时发一条**系统通知**（人在别的页面、窗口被挡住时也能看到）。
- 结束后直接点「开始」，会按设定时长重新计时，不需要先按重置。
- 切页不停。

## 计数

### 细胞计数器

多行手动计数器（如分别数活细胞 / 死细胞、不同象限），每行可重命名、± 计数、单行归零或全部归零，顶部显示总计。

### 血球计数板

**原理**：标准 Neubauer 计数板每个大方格面积 1 mm²、盖片下深度 0.1 mm，对应体积 0.1 mm³ = 0.1 µL = 10⁻⁴ mL。

**公式**

```
平均每格 = (n₁ + n₂ + … + nₖ) / k        k 为实际填写的大方格数（1–4）
cells/mL = 平均每格 × 稀释倍数 × 10⁴
总细胞数 = cells/mL × 总体积(mL)          总体积可选
```

**例**：四格分别 52、48、50、50，台盼蓝 1:1 稀释（稀释倍数 2）→ 平均 50 → 50 × 2 × 10⁴ = 1.0 × 10⁶ cells/mL。

**注意**：每格计数在 20–50 之间较可靠；压线细胞按「数上不数下、数左不数右」的惯例计数。

### CFU 计算

**原理**：把一定体积的稀释菌液涂板，每个可见菌落按来自一个可形成菌落的单位（CFU）计。

**公式**

```
CFU/mL = 菌落数 × 稀释倍数 ÷ 涂布体积(mL)
平均 CFU/mL = 所有「可计平板」CFU/mL 的算术平均
```

- **可计平板**：菌落数在 **30–300** 之间（`CFU_MIN = 30`, `CFU_MAX = 300`）。
  - < 30：统计误差大，标记「太少」，不计入平均；
  - > 300：菌落相互融合、难以分辨，标记「TNTC」（too numerous to count），不计入平均。
- 没有任何可计平板时会提示调整稀释度。
- 涂布体积为空时按 0.1 mL 计。

**例**：10⁻⁴ 稀释液涂 0.1 mL 长出 150 个菌落 → 150 × 10⁴ ÷ 0.1 = **1.5 × 10⁷ CFU/mL**。

**与梯度稀释联动（可选，默认关闭）**

- 勾选「联动梯度稀释」后，如果已在「梯度稀释」里生成过方案，每块平板改为选择**管号**，稀释倍数自动取该管的 `母液浓度 / 该管浓度`。
- 联动时提示条为靛蓝色、管号框描边；未联动时为灰色，稀释倍数手动填写。两种状态一眼可区分，避免误以为数据来自方案。
- 结果里逐块平板列出完整算式 `菌落 × 稀释倍数 ÷ 体积 = CFU/mL`，并标明是否计入平均。

参考：[菌落形成单位（CFU）计算器](https://calculatorlib.com/zh/colony-forming-units-calculator)

## 配液与计算

### 浓度稀释 C₁V₁ = C₂V₂

**原理**：稀释前后溶质的量不变。

**公式**

```
V₁ = C₂ × V₂ / C₁            取母液体积
补溶剂 = V₂ − V₁
溶质质量 = C₂ × V₂            仅质量体积浓度（mg/mL、% 等）时给出
```

**单位换算**：内部统一换算到基准单位后再计算。

| 维度 | 可选单位 | 基准 |
|---|---|---|
| 摩尔浓度 | M、mM、µM、nM | M |
| 质量体积 | g/mL、mg/mL、µg/mL、ng/mL、%（w/v） | mg/mL（1% = 10 mg/mL） |
| 倍数 | X | X |
| 体积 | L、mL、µL、nL | mL |

- 母液和目标必须是**同一维度**（摩尔 / 质量体积 / 倍数之间不能互换，没有分子量无法换算）。
- 目标浓度高于母液时报错。
- 溶剂名称可自定义（默认「水」），显示在结果里。

**例**：10× PBS 配 50 mL 1× → V₁ = 1 × 50 / 10 = 5 mL，补水 45 mL。

### 混合配比

一次配多组分溶液。设终体积 V，每个组分分别设置：

- **目标**：终浓度（摩尔 / 质量体积 / 倍数），或目标质量；
- **母液**：溶液（有浓度）或固体（直接称）。

**公式**（下标 t = 目标，s = 母液）

| 目标 \ 母液 | 溶液 | 固体 |
|---|---|---|
| 质量体积浓度 Cₜ | 取 = Cₜ × V / Cₛ | 称 = Cₜ × V |
| 摩尔 / 倍数浓度 Cₜ | 取 = Cₜ × V / Cₛ（需同维度） | 不支持（缺分子量，请改用质量目标） |
| 质量 m | 取 = m / Cₛ（母液需为质量体积浓度） | 称 = m |

```
补液 = V − Σ(各液体组分取用体积)
```

- 各液体组分体积之和超过终体积时会提示（补液为负）。
- 补液名称可自定义。结果可导出 CSV、打印，或推送到手机。

### 梯度稀释

**按目标浓度驱动**：先定每管要的终浓度，再反算取多少母液。

**两种给定方式**

1. **范围 + 管数**（等比梯度）：起始浓度 a、终止浓度 b、管数 n（2–12）

   ```
   公比 f = (a / b)^(1 / (n − 1))
   第 i 管浓度 cᵢ = a / f^(i−1)        i = 1 … n
   ```

2. **目标浓度列表**：直接写各管终浓度，逗号 / 空格分隔，如 `100, 50, 25, 12.5`。

**每管配法**：每管都**从母液平行稀释**（不是逐管转移），误差不会逐级累积。

```
取母液 = V × cᵢ / C母液
补稀释剂 = V − 取母液
稀释倍数 = C母液 / cᵢ
```

- 任何目标浓度都不能高于母液浓度。
- 生成的方案（各管浓度和稀释倍数）会保存下来，供 [CFU 计算](#cfu-计算) 联动使用。

**例**：母液 100 ng/µL，范围 100 → 1.5625、7 管 → 公比 2，各管 100、50、25、12.5、6.25、3.125、1.5625 ng/µL；每管 100 µL 时，第 3 管取母液 25 µL + 补 75 µL。

### 组装配比（Gibson / Seamless）

适用于 Gibson、NEBuilder HiFi、ClonExpress、In-Fusion 等同源重组组装。**只需要输入 µL，结果也只给 µL**。

**约定**

- Master Mix 为 **2×**（`mixFactor = 2`），占反应总体积的一半；
- 剩余体积 **全部** 分给载体和插入片段，**不另加水**；
- 插入片段 : 载体 = **3 : 1**（摩尔比，可改）；
- 预设反应总体积 6 µL（可改）。

**公式**

dsDNA 平均每 bp 约 660 g/mol，所以：

```
1 pmol 的质量(ng) = 0.66 × bp
每 µL 母液所含 pmol：k = 浓度(ng/µL) / (0.66 × bp)

Mix 体积 = V / 2
可分配体积 R = V − Mix

设载体取 v µL，则载体 pmol = v·k_vec
每个插入片段 i 需要 ratio × v·k_vec pmol → 取 vᵢ = ratio × v × k_vec / kᵢ

约束：v + Σvᵢ = R
⇒ v = R / (1 + ratio × k_vec × Σ(1 / kᵢ))
```

即按各片段的长度和浓度，自动把剩余体积在载体和插入片段之间分配，保证摩尔比正好是 ratio : 1。

- 任一组分取量 < 0.05 µL 时提示（难以准确移液），建议提高母液浓度或增大反应体积。
- 支持多个插入片段。

### OD260 核酸定量

**原理**：核酸在 260 nm 有吸收峰，按朗伯-比尔定律浓度与吸光度成正比。

**公式**

```
浓度(ng/µL) = A260 × 系数 × 稀释倍数 ÷ 光程(cm)
A260/280 = A260 ÷ A280
A260/230 = A260 ÷ A230                    填了 A230 才算
```

| 类型 | 系数（ng/µL 每 A260） | 每单位平均分子量 |
|---|---|---|
| dsDNA | 50 | 660 g/mol 每 bp |
| ssDNA | 33 | 330 g/mol 每 nt |
| RNA | 40 | 340 g/mol 每 nt |

**纯度参考**：A260/280 ≈ 1.8（DNA）、≈ 2.0（RNA）为纯；偏低提示蛋白或酚污染。A260/230 一般应在 2.0–2.2，偏低提示盐、胍盐、多糖或有机溶剂残留。界面上 A260/280 在 1.7–2.1 之间显示为绿色。

**拷贝数**（填了长度时）：

```
分子量 MW = 长度 × 每单位平均分子量
拷贝数/µL = 浓度(ng/µL) × 6.022×10²³ ÷ (MW × 10⁹)
```

### 分子量

- **化学式**：按原子量求和，支持括号和方括号嵌套，如 `CuSO4(H2O)5`、`Ca3(PO4)2`。目前收录常见元素（H、C、N、O、F、Na、Mg、P、S、Cl、K、Ca、Fe、Cu、Zn、Mn、Co、Mo、Se、I、Br、Li、B、Si、Al），遇到未收录元素会报无法解析。
- **核酸序列**（平均残基近似）：

  ```
  dsDNA ≈ 长度(bp) × 660 Da
  ssDNA ≈ 长度(nt) × 330 Da
  RNA   ≈ 长度(nt) × 340 Da
  ```

  这是平均值估算，不区分具体碱基组成，也不含末端磷酸。
- **蛋白序列**：各氨基酸**残基**质量求和，再加一分子水 18.02 Da（N 端的 H 和 C 端的 OH）。只接受 20 种标准氨基酸的单字母代码。

## 通用操作

- **两种视图**：「单个工具」（左侧列表 + 右侧当前工具，默认）和「工作台」（多个工具以磁贴网格同屏显示）。
- **排序**：左侧列表长按拖动；工作台里长按卡片空白处拖动，右上角切整栏 / 半栏。两种视图共用同一个顺序。
- **收藏 / 隐藏**：悬停列表项点 ☆ 置顶到「常用」，点眼睛图标隐藏；隐藏的工具收在「已隐藏」里，随时可恢复。拖进「常用」区域也会自动收藏。
- 以上视图和顺序设置、溶剂名、整栏 / 半栏、CFU 联动开关都保存在本地（`toolPrefs`），重启后保留。
- 大部分计算器的结果可以导出 CSV、打印，或推送到手机。
